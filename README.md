# Analisador-Sintatico

Analisador Sintático em python para a disciplina Compiladores do curso Ciências da Computação 8º semestre do IFCE Maracanaú.

## Como Executar

### Executar o analisador

```bash
python parser.py
```

### Executar testes

```bash
pytest test_parser.py
```

### Executar runner do professor

```bash
python test_parser.py
```

### Gerar árvores sintáticas abstratas

```bash
python generate_trees.py
```

## Requisitos

- Python 3.x
- pytest
- matplotlib
